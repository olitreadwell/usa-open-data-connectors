# Triage labels

The engineering skills speak in five canonical triage roles. This file maps
those roles to the label strings used in this repo's tracker.

| Canonical role | Label here | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent to pick up |
| `ready-for-human` | `ready-for-human` | Needs a human to implement |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a role, apply the label string from the right-hand column.
Edit that column if the tracker uses different vocabulary; do not rename the
roles on the left.
